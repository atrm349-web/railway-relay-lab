# 铁路继电器 · 3D 交互实验台

面向《车站信号自动控制》学习的中文交互模型。采用本地 Three.js r160，无需账号、API Key 或联网依赖即可运行离线版。在线版通过 Sites 提供私有访问。

## 打开与操作

双击 `dist/index.html`，用 Chrome、Edge 或 Safari 打开；保留整个 `dist` 文件夹，不能只移动其中的 HTML。若浏览器对本地文件有限制，可在项目目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

然后打开 `http://127.0.0.1:8765/`。运行环境需要支持 WebGL。未能创建三维画布时，页面会明确报告错误，电路图与状态说明仍可使用。

- 拖动模型旋转，滚轮缩放；“立体／正面／侧面”切换视角。
- 点击实体或部件按钮，查看作用；方框标出所选部件。
- 聚焦模型后，方向键旋转，`+`／`-` 缩放。
- 透明外壳、部件标注、磁路示意、慢动作及拆解滑块均可独立操作。
- “导出 GLB 模型”保存当前继电器的机构姿态，包含材质和几何，可导入 Blender 等软件；不包含文字、交互与磁路动画。

## 建议学习顺序

1. **前、后接点**：先断电，再通电，对照 11（中）、12（前）、13（后）接点；观察两个独立负载交替通断。
2. **无极**：正向 → 反向 → 断电。两种电流方向均能吸起；断电后重力返回。
3. **偏极**：同样的操作，对比规定极性吸起与反极性不吸起。此处按 JPXC-1000 的 1 正、4 负规则演示。
4. **极性保持**：正向 → 断电 → 反向 → 断电。确认断电保持上次位置，区别于持续供电的自闭电路。
5. **整流式**：比较交流与半波整流后的定性波形，再切到“轨道运行”。
6. **轨道运行**：让列车完整通过，观察前轮进入到最后轮对离开之间 GJ 的状态；拖动位置可暂停研究。
7. **故障与多受端**：分别切断送电、模拟钢轨路径断路和受电线断开。打开“一送两受”并设置分支占用，观察支 DGJ₁ 的前接点如何切断主 DGJ 励磁。
8. **二元二位**：保留轨道信号，分别改变局部电源、频率和相位条件，观察不能满足检测条件时 GJ 落下。

每个模块都有动作链、实时状态、部件说明、一题预测练习、教材页码及模型边界。运行记录中的秒数为动画运行时间；手动改变条件不增加运行时间，记录明确标注 GJ 的目标状态。

## 概念边界

“常开／常闭”通常用于描述接点，“无极／偏极／极性保持”等描述继电器类型。对普通单稳态型，释放时中—前断开、中—后接通；铁路“常态”按设备通常状态定义，GJ 在正常空闲时的常态是吸起，不能将“常态”与“断电”混用。极性保持型不能套用“失电必落下”。

轨道继电器 GJ 是功能名称，不是一种统一的物理结构：本实验分别演示 50 Hz 整流式和 25 Hz 相敏式轨道电路。其他继电器的单体原理在“继电器原理”中独立学习，不把它们都直接接成 GJ。

空闲检测成立只提供一个联锁条件，不能独自决定信号开放。GJ 落下表示不能证明空闲，可能来自列车分路，也可能来自故障。模型没有实现整站进路、道岔控制或信号开放逻辑。

## 主要依据与简化

主要依据：岳强主编《车站信号自动控制》第二版，中国铁道出版社，2024 年。

| 内容 | 教材位置 |
| --- | --- |
| AX 机构、无极、偏极、极性保持 | 第 4.1 节，书内 44—47 页／PDF 54—57 页，图 4.1.1—4.1.5 |
| 接点、编号、常态 | 第 4.1.2 节，书内 47—49 页／PDF 57—59 页，图 4.1.6—4.1.7 |
| 50 Hz 整流式与一送多受 | 第 5.3.1 节，书内 77—78 页／PDF 87—88 页，图 5.3.1—5.3.2 |
| 25 Hz 相敏轨道电路 | 第 5.3.2 节，书内 78—79 页／PDF 88—89 页，图 5.3.3 |

相关原图已核对。图 4.1.5 的正文有 (a)/(b) 对应交叉，按正文明确的电流规则建立状态：1 进 4 出为定位，4 进 1 出为反位，断电保持。

- AX 模型提取教材核心机构，不是实物尺寸复刻；双线圈、接点组数量、线圈匝数、动作间隙与动画时间为教学设定。
- 偏极、极性保持的永久磁铁与磁路布局做了简化，准确表达动作规则，不表示具体产品完整机械结构。
- 教材没有展开二元二位型内部结构。双电磁系统、铝翼与感应转矩是**补充原理示意**，不对应特定产品构造。
- 整流模块与波形属于教学等效，不是 JZXC-480 内部接线图；交流路径上的流动点仅表示路径中有电流，不表示瞬时电流方向。
- 不计算实际电流、磁场、吸力、工作值、释放值、真实相角和轨道参数。规定动作条件以离散开关表示。
- 轮对视为理想低阻分路，轨道断路为单一导电路径断开；不能推广为所有现场断轨都能检出。
- 接点采用先断后接动画，转换中前、后接点可同时断开；右侧同步显示“转换中”。GLB 是静态姿态，交互动画由网页程序提供。
- 一送两受中主 DGJ 还检查支 DGJ₁ 的前接点。画面提取总检查关系，没有复刻完整站场与全部电气接线。

## 文件与验证

- `dist/`：可直接运行的离线实验台。
- `outputs/models/`：五类机构各两种位置，共 10 个静态 GLB 模型；`picked` 表示吸起／定位，`dropped` 表示落下／反位。
- `tests/logic.test.cjs`：状态、接点互补、轮对边界、故障、相敏与极性保持自检。
- `tests/export.test.cjs`：GLB 导出、缓冲区、几何和索引边界自检，并生成模型文件。
- `outputs/验证记录.md`：实际验证结果与限制。

```sh
node tests/logic.test.cjs
node tests/export.test.cjs
```

Three.js 采用 MIT 许可，原许可证为 `dist/vendor/THREE-LICENSE.txt`。使用固定版本的经典脚本构建，便于双击离线运行；控制台可能出现该构建形式的弃用提示，不影响此固定版本的运行。
