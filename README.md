## 操作与学习

拖动旋转、滚轮缩放；可切正面、侧面、立体。打开外壳、拆解或慢动作，对照接点图；点击部件查看原理。文字已改为独立高清文字层，固定字号，随模型定位并避让重叠，不再使用低清文字贴图。

依次比较无极正反向均吸起、偏极只在规定极性吸起、极性保持断电不变位。常开/常闭指接点，铁路“常态”按设备通常状态确定：GJ正常空闲时常态为吸起，不能将常态当成断电。

轨道运行按教材第5.3节绑定：图5.3.1的AC220 V、BG₁-50、2.2 Ω/220 W限流、钢轨、BZ₄及JZXC-480的8/7端；图5.3.2(a)支DGJ₁前接点串入主DGJ励磁回路；图5.3.3轨道与局部双输入，Z/HF跨接轨道侧，C并接局部侧。

列车进入时轮对低阻分路，最后轮对离开后恢复检测条件。故障同样可能使GJ落下，不能将“落下”唯一理解为有车。GJ吸起只提供空闲条件，不单独决定信号开放。

## 接点放大、并排比较与部件来源

- “接点局部放大”隔离同一模型的一组完整接点。可暂停在后接点闭合、转换中双断、前接点闭合三个位置，也可恢复随供电动作。逐步观察是手动机构展示，线圈供电单独显示。
- 四组并排比较共用正向、反向、断电控制，分别保留各型号的极性、永磁保持和延时状态。每侧有独立3D机构、二维接点图和状态文字。
- 点击3D接点、二维接点支路或部件按钮，右侧显示对应教材摘图和区域框，并可打开完整原页。下方“部件与来源核对表”列出部件、PDF/书内页码与核实程度。
- 线圈上的低分辨率印字贴图已撤下，参数由高清HTML标注和型号卡显示。接点组、匝数、装配细节均保留教学比例说明。

## 列车、受电弓与运行历史

CR400AF基础型车头、驾驶窗与红银涂装参考中国中车官方产品页照片。连续曲面替换分体鼻锥，展示四根车轴、两组转向架、单臂受电弓、绝缘支座及双滑板。车体采用缩短教学表达，受电弓具体型号、车型编组、安装车位及内部设备尚未按车辆装配图校准。

官方参考为 https://www.crrcgc.cc/crrcgc/2026-05/09/article_2026050917102785945.html 。程序离线运行，参考链接仅在用户主动打开时联网。

“03”中可切换升降弓、接触网供电、主断路器与制动。降弓或接触网失电使主断路器断开，恢复后需手动闭合。升弓到位后才给牵引条件，失去牵引后可惰行，制动减速至停车。移动中换向需先制动停车。轮对转动、车端方向灯光和弓头高度随状态联动，接触线、承力索、吊弦与支柱用于观察受流关系。

运行采用站场坐标单位，教学最高速度18坐标单位/s、牵引加速度4坐标单位/s²、制动减速度8坐标单位/s²、惰行减速度0.3坐标单位/s²。慢动作按四倍时长推进。上述参数属于演示设定，真实车辆速度、牵引制动曲线、编组质量、轮轨黏着、坡道阻力及弓网接触力尚未校准。

运行记录按教材第9.3节图9.3.1—9.3.2（书173—176/PDF183—186）记录区段占用、出清、QJJ、1LJ、2LJ与FDGJ三秒缓放。滑块经过的边界均被采样，移动滑块本身不补记时间。暂停列车位置后继电器延时继续，施加制动则按演示减速度停车。初始位置之前的通过过程不自动补造，题库场景带有明确的预置过程回放。

倒退会记录方向变化并作废未完成的正向记录，保持自动解锁闭锁。本轮尚未建立反向进路及完整双向LJ电路。可观察倒退造成的区段重新占用，之后应按具体场景重新排路或办理教材规定的人工解锁。

“导出本次运行记录”保存JSON，含事件时间、位置、状态和教材页码。界面显示最近35项，内存保留最近300项并记录已移出的数量。

## 页码与边界

主要依据：岳强《车站信号自动控制》第二版（2024），第4.1节书内44—51页/PDF54—61页，第5.3节书内77—79页/PDF87—89页。型号表逐行核对PDF60原图。

型号参数、磁路关系和功能依据见各模型的教材页。接点为展开观察排列。材料、重锤层数、螺钉、线材形状及安装尺寸未经厂家图或实物测量核实。整流器与时间继电器电路板、电容的推测安装实体已移除。相敏右侧机构保留为明确标注的补充原理示意。

图4.1.5正文(a)/(b)对应交叉，采用明确电流规则：1进4出为定位，4进1出为反位，断电保持。JZXC-480释放值在表4.1.4为AC4.3 V，续表举例为AC4.8 V；保留差异，不合成真实阈值。图5.3.3局部电源端标签有辨识限制，不补写电压。

仿真为离散教学条件。缓放台采用0.5s、0.46s、0.16s保持再释放，慢动作时间放慢4倍。长延时显示教材秒数，普通演示加速60倍、慢动作加速15倍。站场DEP代表正线发车，接车IG/3G和DEP均为180s，调车为30s。ZRA持续检查完整空闲，检查中断后须重新办理。SGA仅作用于对应区段并先检查空闲及QJJ落下。站场交互通过事件历史推进状态，保留旧数据直接求值接口以兼容静态题目。倒退采用上述保守教学分支，多车、完整反向进路及断轨全故障集未建模。不计算真实磁场、磁吸力、轨道电压分配及连续相角。流动点不表示磁通粒子或交流瞬时方向。完整分支站场、绕组和同名端接线以原图为准。
