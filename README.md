## 🎛️ 操作指南与教学要点

- **3D 视图控制**：鼠标拖动旋转、滚轮缩放，一键切换立体 / 正面 / 侧面视角；支持透明外壳、0–100% 爆炸拆解、慢动作与原生 Web Audio 机械音效，标注采用独立高清文字层并自动避让重叠。
- **接点微距与四组并排对比**：可在“接点局部放大”中定格后接点闭合 → 先断后接双断悬空 → 前接点闭合三态；四组并排对比共用正向/反向/断电激励，直观辨析无极、偏极、极性保持与缓放差异。
- **“常开/常闭”与铁路“常态”**：常开/常闭仅指继电器完全失电状态；铁路“常态”依设备通常状态与故障—安全原则确定（如 `GJ`、`DBJ`、`SJ`、`DJ` 常态吸起↑，`XJ`、`1DQJ`、`FDGJ` 常态落下↓）。
- **轨道电路分路**：严格绑定图 5.3.1（`AC 220 V → BG₁-50 → 2.2 Ω/220 W → 钢轨 → BZ₄ → JZXC-480`）、图 5.3.2(a)（支 `DGJ₁` 前接点串入主 `DGJ`）与图 5.3.3（25 Hz 局部/轨道双输入）；3 节车首轮压入即分路落下 `GJ↓`，须待尾车最后轮对完全出清方恢复。

- **车辆模型**：CR400AF 基础型车头与 3 节教学编组（含四根车轴、两组转向架、单臂受电弓与接触网支柱/吊弦），采用缩短教学比例表达（未按实车装配图校准）。

## 📖 教材页码、仿真边界与勘误说明

- **主要依据**：岳强《车站信号自动控制（第二版）》（2024），逐章逐图核对全书 1–13 章全部 168 幅插图与 127 道复习思考题，并在涉及原书图文前后差异处（如 PDF p.51、p.52、p.80、p.149、p.201 等）以醒目勘误提示透明标注，仿真均按安全与物理正确逻辑运行。
- **典型核查边界**：
  - 图 4.1.5 正文 (a)/(b) 对应交叉，本仿真统一采用明确电流规则：1 进 4 出为定位，4 进 1 出为反位，断电永磁保持；
  - `JZXC-480` 释放值表 4.1.4 为 `AC 4.3 V`、续表举例为 `AC 4.8 V`，保留原文差异不强行合成；
  - 教学仿真采用离散条件与代表性动力学/电磁公式（长延时 3 min / 30 s 演示按比例加速），不替代有限元电磁场或实车牵引制动标定；`03` 沙盘已支持双车平行、抵触排队与股道占车引导场景，完整双向反向解锁与全断轨故障矩阵仍按保守教学分支处理。
- **第三方许可**：Three.js r160 采用 MIT 许可（见 [THREE-LICENSE.txt](dist/vendor/THREE-LICENSE.txt)）；固定版本经典脚本在 Node 环境下可能输出弃用提示，不影响离线运行。
